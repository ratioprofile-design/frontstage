3. 5. Later browser access means shared projects and synchronization. Web and Windows clients follow the working macOS product and shared document contracts.

## Popup working specification

- Double-click or press Return on a selected beat to open the editor; provide an explicit context-menu action too. These are implementation defaults until the reference interaction can be checked.
- Present a native floating panel near the selected beat. Keep the whiteboard visible and preserve pan/zoom when it opens or closes. Avoid replacing the workspace or using a full-screen editor.
- Bind the editor to a stable beat/snippet ID, not the current global selection. Opening another beat must finish the previous edit safely; multiple editor instances must not share the existing single text-view controller accidentally.
- Reuse the native screenplay text system. Preserve paragraph types, Unicode, inline formatting and source protection. All surfaces edit the same underlying content.
- Use live project updates with coalesced undo and recovery. As the initial behavior, Escape/click-away dismisses the panel while retaining edits; make that behavior visible and compare it with the actual product. Never discard changes silently or use Escape to undo unrelated work.
- Support title/synopsis and snippet text early. Add beat type, characters, tags and Must Be Caused with persistence and validation. Treat exact attachment/metadata controls as reference-dependent details.
